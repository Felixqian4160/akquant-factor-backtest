# v2 快筛 — 去重矩阵「动态打分 + top-20 投票」六路对照（2026-10-10）

合同要点：
- 因子池：去重后 413 个唯一代表（`data/wavehunter_hs300_v34_dedup_20261010.parquet`）
- 全部结算合规：打分只使用 t ≤ i-21 的已结算行；IC 行结算于 d+21
- 选 top-20 因子；每因子按 score 符号提名 top-10（score≥0）或 bottom-10（score<0）股票
- 投票：min_votes bull=2 / bear=4，股票 5-10 只（与 causal v1 一致）
- 执行：v41 runner（T+1 NextOpen + 成本 + CA），offset=0，2010-2025
- **单 offset 快筛，非最终结论**

## 观察

1. **全部 v2 因果臂 > causal v1（4.32%）**：去重 + top-20 扩源 + 符号方向处理带来了 +1.3pp（k20 5.60%）到 +7.8pp（k120）的提升。
2. **窗口长度有单调性**：20 → 60 → 120 递增（5.6% → 9.4% → 12.2%），k250 回落（7.6%）。中期（≈6 个月）因子动量有一点信息，短窗（20 天）基本是噪声——与此前"20 天追涨无效"的结论一致。
3. **static 领先（18.57%）但含 in-sample**：因子集合按 2010-2025 全期均值选取，实盘不可得（上界参考）。需"诚实化"（分段/滚动选集合）后才能判断。
4. **IC 臂 6.72%**：再次确认弱于长窗收益打分。
5. **所有臂 MDD 48–56%**：收益底色仍是小盘/流动性暴露；风险远高于指数。
6. 单 offset、单时期——下一步必须做稳健性（10 offset × 2 窗口）。

## 后续 A：static 诚实化 + 慢动态（2018-2025 分段）

两路新 arm（其余合同与快筛一致，结算合规）：

### 关键读数

1. **static_2017 诚实版扛住了 OOS**：21.23%（vs 全期内选 25.59%，仅衰减 −4.4pp）——固定集合不是全期调参的假象。
2. **年度重选反而更差**（roll250 14.43%）→"冻结集合 > 低频重估"，至少在本窗口。
3. **但相对等权基准：static_2017 Sharpe 0.877 ≈ 等权全池 0.874**——其 +4.5pp 超额收益是用深得多的回撤（−44.9% vs −26.1%）换来的小盘/流动性 beta 倾斜，**风险调整后没有 alpha**。
4. **全部动态臂段内跑输等权基准**（7.9%–9.9%，ic 1.2%）。
5. 本框架/本窗口结论：选股层相对"持有全池等权"无风险调整 alpha。

## 待办（下一步选项）

- A：static_2017 vs 等权基准正面对比（日度超额曲线、逐年超额、回撤对比、2010-2017 分段）+ 容量审计 → 定案"是否只剩 beta"
- B：转向：等权底仓 + 风险开关/动态仓位（V32 dynamic target 路线延伸，已验证可砍 MDD）
