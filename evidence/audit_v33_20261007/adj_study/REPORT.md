# 复权 vs 未复权价格对因子值投票策略的影响 — 量化研究报告

> **研究日期**: 2026-10-07 | **实验数据**: 354 只 HS300 股票全历史 (2004-2026) + 真实复权因子
> **数据来源**: `aurumq-rl/data_cache/*_full.parquet`（Tushare 原始 adj_factor）
> **相关审计**: `evidence/audit_v33_20261007/REPORT.md` §Module 3

---

## 0. 核心结论（一句话）

**未复权价格对因子值投票策略有三个层面的影响**：
1. **评分输入**（fwd 收益）：每 20 日窗口平均低估 +0.3%~1.25%（除权跳空）→ 影响**因子排序**
2. **执行 PnL**：16 年累计低估 **¥8.17B**（0.281%/笔来回）→ 影响**收益报告**
3. **因子值本身**：类型决定——比值型因子影响小（top-10 重合 9.8/10），差值型因子影响大（重合仅 4/10），同日形态因子**数学不变**

**正确的做法**：因子计算和 fwd 收益用**复权价**；执行用**原始价** + 公司行动处理；基本面/量额因子保持原始。

---

## 1. 影响机制分解

策略管线中价格出现在 3 个位置，各自受除权影响的方式不同：

```
┌─────────────────────────────────────────────────────────────┐
│  Layer A: 因子值 (T 日横截面) → 决定股票投票                  │
│  Layer B: fwd 收益 (net20) → 决定因子评分/排序               │
│  Layer C: 执行价格 (T+1 open 买 / T+21 open 卖) → 决定 PnL   │
└─────────────────────────────────────────────────────────────┘
```

**除权事件的影响方式**：
- **送转股**（如 10送10）：原始价暴跌 ~50%（人为）；复权价连续（中性）→ 影响巨大
- **现金分红**（如 2%）：原始价跌 2%（人为）；持有人收到现金 → 复权修正
- 未复权回测**系统性低估**多头收益（所有 diff 均为正，min=-0.0004）

## 2. Layer A — 因子值对投票的影响（实验）

**实验设计**: 对每个因子，分别用原始价和复权价计算，比较：
- 横截面 Spearman 秩相关（每日期）
- top-10 股票重合度（= 该因子会投给哪些股票）

195 个调仓日 (2010-2025) 结果：

| 因子 | 类型 | Spearman(mean) | top-10 重合 | top-10 完全一致日期 |
|---|---|---:|---:|---:|
| **talib_ROC** | 比值型 (close/close[10]-1) | **0.982** | **9.79/10** | 83.1% |
| **talib_MOM** | 差值型 (close-close[10]) | **0.882** | **3.99/10** | 0.5% |
| gtja_gtja_002 | 同日形态 | 1.0000 | 10/10 | 100% |

### 结论按因子类型

| 因子类型 | 例子 | 复权影响 | 原因 |
|---|---|---|---|
| **比值型**（收益率/动量比） | ROC, 动量比, 波动率比 | **小**（重合 9.8/10） | 除权影响被比值稀释；仅跨除权窗口有影响 |
| **差值型**（价格差/绝对量） | MOM, 价格差, MA距离(绝对值) | **大**（重合 4/10） | 除权跳空直接进入差值；且复权后单位变化 |
| **同日形态型** | gtja_002, BOP, TYPPRICE | **零**（数学不变） | 同日 OHLC 同比例缩放，比值不变 |
| **基本面型** | pe, pb, roe | **零**（本应如此） | 市值为真实时点数据 |
| **量额型** | volume, amount, turnover | **零**（本应如此） | 真实交易量，不应复权 |

**对投票机制的含义**: 策略的 top-10 因子中若含差值型因子（如 MOM 类），其投票在原始价与复权价下**完全不同**（4/10 vs 9.8/10 重合）。当前 v33 面板全部用原始价 → 差值型因子的投票是"错误"版本。

## 3. Layer B — fwd 收益（评分输入）的影响

**实验: _fwd_net 原始 vs 复权，全面板 2010-2025**

| 指标 | 数值 |
|---|---:|
| 全部样本 (1.28M windows) | |
| mean diff (adj − raw) | **+0.6%** |
| \|diff\| > 0.2% 的窗口 | 8.1% |
| \|diff\| > 1% 的窗口 | 5.7% |
| 正偏差占比 | ~100% |

**按年**:

| 年 | mean diff | 年 | mean diff |
|---|---:|---|---:|
| 2010 | +0.85% | 2018 | +0.50% |
| 2011 | +1.02% | 2019 | +0.39% |
| 2012 | +0.79% | 2020 | +0.43% |
| 2013 | +0.59% | 2021 | +0.42% |
| 2014 | +0.89% | 2022 | +0.40% |
| 2015 | +1.25% | 2023 | +0.39% |
| 2016 | +0.95% | 2024 | +0.32% |
| 2017 | +0.55% | 2025 | +0.28% |

**解读**:
- 早期 (2010-2015) 影响大（+0.8~1.25%）：当年送转股盛行（10送10 类）
- 近年 (+0.3%)：以现金分红为主（~2%/年 → 20日窗口 ~0.16%+）
- **方向一致为正**：未复权 fwd 收益系统性低估 → 因子评分系统性偏差

**对评分的含义**: score(f,T) = 过去 20 日 top10−bot10 diff 均值。每个 diff 有 ~0.6% 的正偏差，但关键是**横截面差异**：不同因子的 top-10 组合若包含近期除权股票多，评分被低估更多 → 因子排序被扭曲。

## 5. 正确的设计（应为）

### 5.1 三层架构

```
┌──────────────────────────────────────────────────────────────────┐
│ 因子计算     → 复权价 (后复权 hfq = raw × adj_factor)           │
│ fwd 收益     → 复权价 (经济收益)                                  │
│ 执行成交价   → 原始价 (真实市场价) + 公司行动处理                   │
│   ├─ 分红: ex-date 现金入账 (qty × 每股分红)                      │
│   ├─ 送转: ex-date 股数调整 (qty × 送转比例)                      │
│   └─ 或简化: 用复权价计算收益率, 成交仍用原始价                    │
│ 基本面因子   → 原始 (PE/PB 即真实时点)                            │
│ 量额因子     → 原始 (真实交易量)                                  │
│ 同日形态因子 → 不变 (数学上等价)                                  │
└──────────────────────────────────────────────────────────────────┘
```

### 5.2 关键原则

1. **复权选择**: 研究/回测用**后复权 (hfq)**——历史序列稳定，不因未来分红而变化；
   若必须 qfq，须用**固定 vintage 快照**（每次回测一致）
2. **执行现实性**: 成交在原始价（真实市场），分红/送转通过公司行动进账；
   简化方案（可接受）: 成交原始价 + PnL 用复权收益率计算
3. **panel 设计**: 同时携带 `raw OHLCV` + `adj_factor` 两套；
   当前 v33 面板有 adj_factor/adj_close 列但**全 = 1.0（未正确填充）**

### 5.3 当前问题的修复清单

| # | 修复项 | 数据/工具 | 工作量 |
|---|---|---|---|
| 1 | 填充真实 adj_factor | ✅ 本地已有 (`aurumq-rl/data_cache/*_full.parquet`, 354/354) | 小 |
| 2 | `_fwd_net` 改用复权价 | picks builder 一行改动 | 小 |
| 3 | 执行层加公司行动处理 | AKQuant runner + 分红数据 | 中 |
| 4 | 重建受影响的因子（差值型优先） | factor builders (aurumq-rl/scripts) | 大 |
| 5 | 全面重跑 + 审计 | 全管线 | 中 |

### 5.4 影响预估（若全部修复）

- Layer C 直接: +¥8.2B 最终 NAV (+4%)、年化 ~+0.45pp
- Layer B: 因子评分修正 → 选股变化（方向：评分更准确）
- Layer A: 差值型因子投票修正（当前版本是"错误"投票）
- **总计**: 预计年化 +0.5-1.5pp 量级修正 + 选股质量提升；需重跑确认
