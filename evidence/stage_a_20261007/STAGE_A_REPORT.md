# Stage A 报告 — 57x 分歧归因 + 抗扰动测试（真实 edge vs 噪声选股）

日期：2026-10-07 | 合同：用户选 A（归因 + 抗扰动）

## 1. 问题陈述

C 方案后发现（表面）：v33 picks 与 v34 picks 结果差 57 倍。需归因：
（a）差异来自哪个修复环节？（b）该策略是真实 edge 还是噪声选股？

## 2. 归因结果

### 2.1 首先修正一个混淆（重要）

深度排查发现：**v34 picks 首次构建误用了 lookback=60**（拷贝 builder 时漏改默认值），
而 v33 全系 lookback=20。修正后重建（lb=20）与 stage-A 矩阵派生完全一致（195/195）。

**修正后对比（全部 lb=20）**：

| picks | Jaccard |
|---|---:|
| v34-lb20 vs v33-lb20 | 0.385 |
| v34-lb20 vs v34-lb60 | 0.272（lookback 效应） |
| fwd_net 单变量效应（p2 vs v34 / p3 vs v33） | 0.731 / 0.740 |

### 2.2 四角数据组合（全部 lb20 + CA 执行）

| 组合 | ann | total% | Sharpe |
|---|---:|---:|---:|
| v33 因子 + raw fwd | 74.6% | 747,100 | 2.18 |
| v33 因子 + adj fwd | 75.6% | 813,504 | 2.18 |
| v34 因子 + raw fwd | 68.1% | 408,123 | 2.01 |
| v34 因子 + adj fwd（canonical） | 65.1% | 303,868 | 1.91 |

**归因结论**：数据修复（因子值 + fwd 口径）合计影响 ≈ −9.5pp ann（74.6→65.1%），
四个合法组合带宽 65.1%~75.6%（±5pp）。**不是 57 倍，是 ~15% 相对修正。**

## 4. 结论

**该策略有真实 edge，不是噪声选股。**

1. **因子收益排名评分带强信号**：随机选因子 ≈ 6.7%/年（≈市场基线），
   评分选因子 ≈ 65.1%/年，z=+22，全部 10 个 null 抽样都不及其一半。
2. **数据修正的真实影响温和**：74.6% → 65.1%/年（−9.5pp），四角带宽 ±5pp，
   不是表面上的 57 倍（那是 lookback 60 vs 20 混淆）。
3. **敏感性仍然显著（诚实标注）**：换 lookback（20↔60）会大幅改变选股与结果
   （Jaccard 0.27）；subsample 扰动 −3pp。策略对参数有真实敏感性，
   但核心信号在扰动下稳定存在（所有变体 ann ≥ 35%，含 lb60 的 35.7%）。
4. **剩余风险**：canonical Sharpe 1.91 仍接近 2.0 警戒线；65% 年化绝对值高，
   需要 stage 5（多 offset 正式验证 + 2026 OOS）进一步确认稳健性。
